**Проєктую інтерфейси вебсервісів для бізнесу, щоб користувачам було простіше почати роботу, налаштувати сервіс і виконувати щоденні задачі.**

- **Мій вибір:** напрям A — продуктова дизайнерка для команд вебпродуктів (з трьох запропонованих: A — команди вебпродуктів, B — сервісний бізнес, C — інженерка, що стала дизайнеркою).
- **Кому адресовано:** роботодавцям у UK та українським продуктовим командам, які наймають UI/UX або Product Designer. Проєктна співпраця — другорядна аудиторія.
- **Перша робота:** MobiBubble.
- **Редакційна примітка:** речення сформулювала та затвердила я на основі напряму A; ризик напряму — спільна концепція та прототип, тому в кейсі чітко позначати межі мого внеску.

## 2. Перелік сторінок

Перша версія сайту — головна та два повні кейси; третій — короткий кейс навчального застосунку. Усі сторінки — англійською та українською з перемикачем EN/UA.

1. **Головна** — коротко представляє мене як дизайнерку інтерфейсів вебсервісів для бізнесу, показує вибрані роботи, професійний шлях і спосіб звʼязку.
2. **Кейс MobiBubble** (головний) — пояснює мої продуктові й дизайн-рішення для бізнесу та клієнта букінг-платформи: від початку роботи й налаштування сервісу до щоденних задач, як-от бронювання.
3. **Кейс Louth Handyman Services** — показує роботу над сайтом локального бізнесу, контентом із замовником та шляхом відвідувача до запиту.
4. **Короткий кейс** застосунку для читання (навчальний концепт) — показує UI-екрани, user flows, конкурентний аналіз і маркетингові скріни для App Store.

Структура кожного кейсу: огляд і роль → задача → зворотний звʼязок → ключові рішення → екрани й адаптивність → результат і висновки.
